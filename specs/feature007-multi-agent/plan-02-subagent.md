# Feature 007 Plan 02：SubAgent

状态：已实现

## 开发者速览
> **一句话**：主 Agent 能把有界任务交给独立成员，查看并回收结果。<br>
> **核心做法**：共享成员生命周期，复用 SessionAgent，所有委派走有来源输入。<br>
> **边界**：最多三个成员且只有一层；写任务使用独立 worktree。<br>
> **风险 / 未验证**：取消、审批与 Session 并发写入必须沿同一持有链收口。<br>
> **当前 / 请审阅**：SubAgent 与存储合同已完成本地验证，证据见统一 Report。

## 实施
1. 创建成员归属、名额预留与运行时能力校验，根 Agent 注入创建函数，避免循环依赖。
2. 增加内部输入与来源记录，不走真实用户 prompt 持久化；审核只读取根用户授权。
3. 接入委派、列表、事件等待、停止和结果读取；限制模型次数、时间和消息大小。
4. 汇总成员审批并按请求 ID 路由；全局停止/关闭等待所有成员和进程结束。
5. 接入 Schema 兼容、主成员历史、显式继续与组清理，TUI 提供查看和操作。

## 验证与停止条件
使用确定性 ModelStream 验证创建、成员禁派生、原始授权、并发隔离、审批路由、取消、恢复及缺失目录历史。复用现有 Session 与工具测试，只新增行为缺口；失败时不留下自动执行的后台任务。
