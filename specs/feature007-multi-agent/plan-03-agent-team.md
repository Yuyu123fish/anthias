# Feature 007 Plan 03：AgentTeam 与收口

状态：已实现

## 开发者速览
> **一句话**：团队保留成员上下文，通过任务和消息持续协作。<br>
> **核心做法**：Lead 分配任务，消息有界入队，状态由根 Session 记录派生。<br>
> **边界**：一个活动 Team，不增加抢单、任务依赖图或自动热恢复。<br>
> **风险 / 未验证**：队列和结束竞争必须保存可核对记录，验证成果需要明确版本。<br>
> **当前 / 请审阅**：Team、统一验证和独立审查已完成，等待开发者验收。

## 实施
1. 在成员运行时上实现建立/结束团队、添加成员、分派和更新任务。
2. 实现同队定向消息、稳定 ID 去重；忙时下一请求前消费，空闲只入队。
3. 接入模型工具和 TUI；支持历史/结果查看及显式继续，关闭仍保护待交付成果。
4. 汇总实际成果版本、恢复与清理结果，更新统一 Tasks、Report 和用户使用说明。

## 验证与停止条件
定向验证团队任务与通信、空闲无调用、重开不自动启动、成员不能扩权及整体关闭。已有可信定向测试不重复运行，完成一次 pnpm verify 和最终独立审查，只修正实际遗漏。没有真实 Provider 授权，报告必须区分本地验证与人工体验。
