## 已完成的行为

1. **模型续轮**：保留同一 Run 内的空 reasoning 状态，在 OpenAI-compatible 消息转换中显式回传空 `reasoning_content`。已有非空 reasoning 保持原值；重试清理失败尝试状态。未增加模型名称分支或 reasoning 历史持久化字段。
2. **结果保存**：短结果直接形成 ToolResult；超过字节、行或模型预算才调用 `save` 保存原文。文件读取的产物只包含本次请求页，行范围及继续位置按最终可见完整行生成。长单行通过产物游标续读；短搜索结果也会明确说明来源未穷尽。
3. **并发**：不同文件的写入可以同时执行，上限仍为四。相同真实文件、硬链接及路径别名形成冲突；目录搜索可能经过文件链接，因此与写入保守串行。Shell、Git、成员生命周期和未知外部操作为顺序屏障。
4. **审批**：AutoAllow 把用户原始授权与解释指代的 Assistant 提案分开，只接受真实用户 entryId 作为授权依据；缺失确认或上下文预算不足回到人工。Full Access 显式启用后跳过两类审批，允许工作区外普通文件读写，仍保留应用数据保护、目标复核、系统破坏硬拒绝和只读成员限制。
5. **TUI**：实际 Editor 支持命令、参数、文件和 `@文件` 的 Tab 补全，兼容 Windows 正反斜杠、盘符、中文及空格目录，不依赖 fd。CLI、`/mode`、状态显示及撤销授权说明均接入 Full Access。
6. **命名**：核查全部 95 个生产文件（Agent 78、TUI 17），修正 Assistant 响应、Context ModelStream、Git 工作树变更集合，以及 Session/模型/TUI 中 Promise、迭代器、消息和审批对象的名称；同步真实消费者，未增加近义公开类型或改动持久化判别值。

## 入口与职责

主调用链为：

`TUI → Agent → Model Adapter → ToolRunner 计划 → 冲突分组 → 预检/授权 → 执行 → finalizeToolResult → AgentEvent / Session`

ToolRunner 声明文件资源访问或串行能力；Agent Loop 选择连续无冲突分组，前驱完成后才准备冲突动作。需要审批的调用逐一绑定原始动作，副作用开始前保存授权和开始记录。执行事件反映实际发生顺序，最终 ToolResult 按模型调用顺序归档。Session 允许多个已授权且尚未完成的开始记录，仍核对审批 ID、所属 Run、工具配对与结果顺序；重新打开历史不执行旧工具。

`finalizeToolResult` 是原文保存与模型预算的统一收敛点。基线中 `ArtifactWriter` 出现在 6 个生产文件，现在只存在于 `session/artifacts.ts` 内部；基础工具与 MCP 不再获得 writer。产物存储的创建入口从 `createWriter` 改为 `save`，保留引用登记、分页读取及关闭能力。SessionArtifactStore 仍为四个方法，Agent package 入口公开导出增量为零。这个变化移除了各工具持有写入、完成和保留决策的调用链，没有把 writer 换名后继续传递。

命令执行器独占持续输出收集：短输出留内存，超过 64 KiB 才创建临时文件，最多保留 32 MiB；仍持续排空管道。交付前关闭句柄，结果收敛在成功或失败后清理临时目录。Session 产物总配额仍为 256 MiB。保存失败不会改写已经发生的工具副作用，正文明确说明原文不可回读；清理不确定性继续通过事件报告。

Full Access 由用户模式选择决定，不依赖 AutoAllow 工作区授权记录。撤销后者不会隐式改变用户选择的模式，TUI 会提示切换模式。可写成员继承根模式，只读成员保持 Plan；应用数据保护仍在真实路径解析后检查。

## 已知限制与待验收

- 没有 OS 沙箱；Full Access 仍以当前系统用户身份执行，提示词不是系统隔离。Shell 不保证应用数据隔离。
- `read_file` 的返回与产物范围已经分页；读取实现仍沿用整份文本解码，未实现任意大文件的流式、有界内存读取。
- 文件候选扫描最多访问 4,000 个条目、深度 8、返回 100 项；跳过 `.git`、`node_modules` 和目录链接。更大目录不会穷尽全部候选。
- Windows 创建末级文件 symlink 返回 EPERM，对应真机回归明确跳过；该路径已有实现，目录 junction、硬链接应用保护与父目录替换在本机验证通过。
- 本地自动测试证明按键与状态行为；真实终端主观体验、真实模型对用户指代的审核质量仍需开发者验收。
