## 交付行为

依据已确认的 [Spec](spec.md)、[Plan](plan.md) 和 [Tasks](tasks.md)，按开发者“一次性实现整个 Feature”的授权完成六个内部增量。

- **分层记忆**：应用根目录 `memory/` 保存用户记忆、项目经验和自动开关。支持通用或项目范围、候选、确认、纠正、遗忘；Git 工作树共享项目身份，非 Git 与未提交仓库同样可用。
- **主动维护**：模型在现有 Run 内通过 `memory` Tool 查询和维护。用户要求关联当前真实用户记录，经验关联已完成 Tool 证据；推断先成为候选，成员只能提交根校验的候选。确认保留原证据，用户确认后的内容不能被自动覆盖。
- **时效**：到期时间控制停止采用，复核时间、分支和文件内容控制待复核。读取不刷新确认时间，不设置所有记忆通用的 TTL。文件证据按成员自己的 Workspace 读取，再转换为项目根下的条件路径。
- **用户入口**：`/memory` 支持列表、类别及状态筛选、详情、保存、纠正、确认、遗忘和自动开关；详情展示来源、确认时间与适用条件。查询可在运行中使用，人工维护遵守空闲边界。Plan 允许受管应用记忆维护。
- **项目规则与编排**：自动加载项目根 AGENTS.md，固定系统规则和工具排序，来源初始快照稳定，真实更新追加。Skill、MCP 和记忆的按需正文位于完整 Tool 组后，读取结果不再重复携带正文。
- **历史与持续运行**：消息通过持久身份关联投影，压缩记录来源版本与折叠边界，遗忘后移除相关来源和受影响摘要。12/60 次模型调用截止已移除，30 分钟、Tool 批量、并发、成员和队列边界保持。

具体命令和例子见 [Quick Start](../../quick-start.md#8-记忆与项目规则)。源码未增加依赖、package、数据库、Host、向量检索或后台整理任务。

## 入口与职责

| 调用链 / 位置 | 职责 |
| --- | --- |
| TUI `memory-view.ts` → `Agent.memory.query/execute` → `memory/index.ts` | 人工查询和受管维护；TUI 不读文件、不构造模型请求 |
| `memory` Tool → 来源及权限核对 → 同一 Memory 入口 → Context 来源采用 | 主动记忆，复用存储与规则；正文保存和会话采用分别报告结果 |
| `memory/schema.ts`、`store.ts`、`selection.ts` | 格式、原子替换与跨进程协调、范围和时效 |
| `context/sources.ts`、`assembly.ts`、`project-rules.ts` | 来源状态、完整 Tool 组后的排列、项目规则读取 |
| `session-agent.ts`、`context/selection.ts`、`session/schema.ts` | 持久身份传递、上下文选择、检查点校验与恢复 |
| `agent.ts`、`startup.ts`、`multi-agent/` | 应用记忆根装配、成员范围、取消与持续运行 |

模型请求的文本顺序为：固定 system → 通用用户记忆 → 初始环境 → AGENTS.md → Skill 目录 → 经验索引与少量正文 → 历史及来源增量。`tools` 是独立请求字段。语义优先级仍为真实用户要求、项目规则、有效经验、用户记忆，来源的传输 role 不改变其身份。

Session 保留“当时发生什么”，memory 保留“现在什么有效”，Context 决定“下次发送什么”。Schema 3 Header 不变，来源与压缩记录增加可选的版本 1 投影元数据，保存保留消息身份、来源版本、来源触发点及折叠边界；新读取器兼容旧记录，不承诺旧版本程序理解新增字段。两个同文消息按不同 entryId 区分，压缩候选整体校验并持久化后才生效。只读历史不加载当前规则来重写过去，明确继续才协调来源。

## 失败、并发与遗忘

条目采用根目录独占写锁、版本比较及临时文件替换；冲突会要求重新读取，保存中断保留最后已提交版本。死亡写锁由独立恢复锁协调，多进程不会同时清理并接管同一锁。若恢复进程自身在持锁时被终止，保留诊断，需关闭其他 Anthias 进程后检查锁文件；程序不抢占可能仍在恢复的进程。

遗忘移除记忆库正文，保留必要的身份、内容摘要和来源抑制信息，旧候选及旧版本不能恢复该条目。`no-send` 另外过滤关联原始记录、受影响的生成内容和完整 Tool 组，并处理引号、反斜杠和换行等文本边界。物理 Session 历史保留，不声称删除其他独立来源中的相同内容。

每次请求和执行未开始的 Tool 前核对撤销；已经发送的请求与已经完成的副作用不能追溯撤回。损坏条目会出现在查询诊断中；无法确认遗忘状态时暂停模型采用及写入，防止旧来源重新生效。

存储成功后，即使随后取消或 Session 采用失败，也如实返回“记忆已保存”；采用失败封口当前 Run，恢复后按版本对齐。敏感值常见模式在入口拒绝，记忆内容和来源不进入 AutoAllow 的真实用户授权集合。

首版单条正文 8 KiB、条目 24 KiB、存储扫描最多 512 条；初始用户摘要和经验索引分别最多 8 KiB，AGENTS.md 完整正文最多 64 KiB，活跃来源合计最多 128 KiB。超出预算显示省略或诊断，必要项目规则不截断。
